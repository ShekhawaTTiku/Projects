# Python Practice Projects

A collection of small command-line Python projects created while practising core programming concepts such as user input, conditionals, loops, randomisation, and simple program flow.

## Projects

| Completed | Project | Description |
| --- | --- | --- |
| 20 September 2026 | Aim Trainer | A reaction and accuracy practice game. |
| 21 September 2026 | Finance Tracker | A simple script for tracking financial entries. |
| 27 September 2026 | Banking System | A basic banking-system simulation. |
| 5 October 2026 | Quiz Game | A five-question general-knowledge quiz. |
| 7 October 2026 | Number Guessing Game | Guess a randomly generated number within a limited number of attempts. |
| 8 October 2026 | Rock Paper Scissors | Play Rock, Paper, Scissors against the computer. |
| 10 October 2026 | Choose Your Own Adventure | A text-based adventure through the Shadow Forest with multiple endings. |

## Run a project

Make sure Python 3 is installed, then run a script from the repository directory:

```bash
python 01_Quiz_Game.py
```

Replace the filename with the project you want to try.
